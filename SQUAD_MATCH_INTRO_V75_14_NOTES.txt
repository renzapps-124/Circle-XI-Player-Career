CIRCLE XI PLAYER CAREER — V75.14
SQUAD NAMES AND POSITIONS IN THE MATCH INTRODUCTION

The problem
The View Squad tab and the match engine built their squads independently from
the same loader, and disagreed the moment that loader came back empty — which is
the common case, since most clubs have no generated player database.

  View Squad tab   loadCircleXIManagerSquad(...) or an inline list of invented
                   names (Kofi Mensah, Leo Hart, ...)
  Match engine     loadCircleXIManagerSquad(...) or "Player 1" ... "Player 11"

So the squad screen showed a named eleven while the match introduction lined up
eleven players called Player 1 to Player 11 — and the formation card, which
labels each marker with a surname, printed "1", "2", "3" because it takes the
last word of the name.

On top of that, only the tiny formation-card markers carried a name at all. The
walkout, lineup, handshake and jog-into-formation stages drew anonymous players.

1. ONE ROSTER PER CLUB
   clubSquadRoster(club) is now the single source. It returns the imported squad
   when the club has one, and otherwise a deterministic generated squad seeded on
   the club id, so the same eleven turn out every match and every club has its
   own names. Both the squad screen and MatchGame read it.

   The generated players carry secondaryPositions, which importedPlayerForPosition
   reads — the old inline fallback did not have that field, so it would have
   thrown the moment a match tried to use it.

   Verified headlessly for a club with no database: an 18 man roster, stable
   across calls, different from another club's, and the match picks a clean XI
   out of it with nobody selected twice.

       RB      2   Adam Duarte
       CB     13   Jonas Okonkwo
       CB      3   Kenji Fischer

   A squad-mate wearing the career player's number used to be deleted from the
   list, leaving a short squad. They are renumbered instead, so the squad stays
   at 18 with unique numbers.

2. NAMES AND POSITIONS ON THE PITCH DURING THE INTRODUCTION
   Every player now carries a tag through the walkout, lineup, handshakes and
   jog into formation: surname on top, shirt number and match position beneath.
   The career player's tag is highlighted in yellow. Tags fade in with the stage
   and fade out at kick-off.

   One thing this exposed: the pitch is drawn through a rotated world transform,
   so anything written in world space reads sideways on screen. The existing YOU
   marker had been rendering rotated for that reason. Both the new tags and that
   marker now cancel the rotation at their anchor while keeping the world scale,
   so they read horizontally at any camera angle or zoom.

Verified in the running game
A live career at a club with no generated database — previously the worst case:

  squad screen        18 players, unique shirt numbers
  match introduction  11 names read off the walkout, all in the squad list

The surnames read off the walkout (NOVAK, MARCHETTI, NAKAMURA, SORENSEN,
IONESCU, FISCHER, BAKKER, DUARTE, SALVATORE, ADEYEMI, APPIAH) are all in the
squad the View Squad tab lists.
