# Circle XI v77.7.1 – Beard Fit Improvement

This patch improves facial-hair fitting so Goatee, Short Beard and Full Beard conform more naturally to all face shapes.

## Changes
- Facial hair now derives its width from jaw width and chin width rather than using a mostly fixed overlay.
- Goatee now reshapes with narrower and wider chins.
- Short Beard now follows jaw width more closely and sits higher/lower more naturally on different faces.
- Full Beard now expands around wider jaws and defined jaws without erasing the face structure.
- Moustache width now follows the fitted lower-face proportions instead of staying fixed.
- Stubble now traces the face contour more consistently.
- Beard fitting remains runtime-generated so older careers automatically benefit.

## Version
- Game script cache updated to `77.7.1`
- Visual identity runtime tag updated to `v77.7.1-beard-fit`
