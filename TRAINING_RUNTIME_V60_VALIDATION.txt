CIRCLE XI PLAYER CAREER — TRAINING RUNTIME v60 VALIDATION
==========================================================
Build: v60.0-training-runtime-reliability
Date: 2026-08-18

PURPOSE
-------
Restore the shared Training Centre runtime after a regression where training sessions could fail to initialise or appear not to load.

ROOT CAUSES FIXED
-----------------
1. Tactical training startup crash:
   The Tactical HUD treated a null bufferedAction as an object because typeof null === "object", then attempted to read primaryKey from null. The check is now null-safe.

2. Performance Gym runtime corruption:
   The shared performance-gym athlete renderer was truncated/corrupted and contained input/stroke logic in the wrong function. The complete shared athlete renderer and performanceGymStroke routine have been restored.

3. Fragile global training boot path:
   Training opening/starting now runs through a guarded runtime manager with compatibility defaults, cleanup, watchdogs, visible recovery state, retry support and diagnostic status.

RUNTIME SAFEGUARDS
------------------
- Validates session ID before launch.
- Applies safe defaults for missing player attributes in older saves.
- Clears stale training state before opening another drill.
- Uses a 5 second load/start watchdog.
- Converts startup exceptions into a recoverable training error state instead of a dead screen.
- Restores the Retry Drill action after boot failure.
- Clears held/pressed training input state on cleanup.
- Clears training watchdogs on exit.
- Exposes window.__circleTrainingRuntime for diagnostic smoke tests.
- Asset cache version updated to v60.0.0.
