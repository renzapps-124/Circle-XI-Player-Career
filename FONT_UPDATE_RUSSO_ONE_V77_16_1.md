# Russo One Font Update v77.16.1

The uploaded Russo One font has been applied directly to the Circle XI: Player Career game build.

## Changes
- Added `assets/fonts/RussoOne-Regular.ttf`
- Added the Russo One OFL licence alongside the font asset
- Registered Russo One locally with `@font-face`
- Replaced the global UI font stack with Russo One
- Applied Russo One across menus, buttons, inputs, labels, panels, HUD text and career screens
- Replaced explicit specialist font families in `styles.css` so the game no longer falls back to Trebuchet, monospace, cursive or system fonts
- Updated generated SVG crest lettering in `game.js` to use Russo One
- Updated the stylesheet and script cache version to `77.16.1`
- Added screenshots from the modified game UI under `SCREENSHOTS/v77_16_1_russo_one/`

## Font
Russo One Regular, supplied by the user.
